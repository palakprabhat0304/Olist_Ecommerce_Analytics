I recently completed a SQL and customer analytics project using the Olist Brazilian E-Commerce dataset.

The goal was to move beyond basic sales reporting and understand both revenue performance and customer behavior.

I built the analysis in PostgreSQL, using a raw → staging → analytics workflow. The project includes monthly revenue analysis, product-category performance, average order value by state, RFM customer segmentation, and cohort retention analysis.

For the customer side, I used Recency, Frequency, and Monetary value to classify customers into segments such as Champions, Loyal Customers, At Risk, and Lost. I also built cohort retention analysis to understand how customer activity changes after the first purchase.

The final step is an executive BI dashboard designed around four questions: how much are we selling, who drives the value, where is revenue concentrated, and are customers returning?

This project helped me practice translating SQL outputs into business-focused insights rather than treating analysis as an end in itself.
